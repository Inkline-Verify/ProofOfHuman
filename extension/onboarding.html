inkline / setup

Three checks and a test email. This page re-checks live. Leave it open while you fix anything missing.

Inkline requires macOS 27 or later. Upgrade to enable the stamp. Your emails send normally without it.

[ .. ]Helper app installed

One command in Terminal. It downloads the notarized helper from the GitHub release, verifies its checksum, connects it to Chrome, and enrolls this Mac:
curl -fsSL https://raw.githubusercontent.com/Inkline-Verify/ProofOfHuman/main/install.sh -o install.sh && sh install.sh

[ .. ]Enrolled with the notary

Run the install command above again. Enrollment is its last step. It creates a fingerprint-locked key in this Mac's Secure Enclave.

[ .. ]Pick your stamp

Optional. Choose a colour and wording. The receipt is identical whatever you pick.

[ .. ]Send a test email

Compose a Gmail message to yourself and hit Send. The approval window appears, press Touch ID, and the received email carries the Verified with Inkline footer.
